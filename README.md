# CAEP Three-Year Plan Dashboard

Targets from the CAEP three-year plans (NOVA) beside the outcomes recorded in DataVista,
for every consortium and member agency. The page is self-contained and is served at
https://greghilljr.github.io/caep-three-year-dashboard/.

This repository holds only the built page. It is published from a separate, private
repository that contains the data pipeline and the report; do not edit the page here,
since the next publish will overwrite it.
